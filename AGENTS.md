# AGENTS.md

UniOne NestJS — NestJS integration of the UniOne Node.js SDK (`unione`) for the UniOne transactional email Web API (Web API 1.90).

## Working on this repository

- **Generated code.** The whole package is generated by the UniOne team from the UniOne Web API OpenAPI spec (Web API 1.90): sources, docs, README.md and this file. Do not hand-edit it: the next release replaces the content of this repository. Report problems and requests in the issues of this repository (https://github.com/unione-repo/unione-nestjs).
- **Build and check:**

  ```bash
  npm install
  npm pack --dry-run
  ```

- **Source label.** Every request carries the query parameter `platform=nestjs.1.1.2,node-sdk.2.1.2` (this package, then the SDK it is built on).
- **Tests.** Before a release the generator installs the package into a test app of NestJS and checks the client, the webhook endpoint and the mailer against a mock of the API: no real API key, no real sends.
- **Release.** The version (1.1.2 in package.json) and the tag `v1.1.2` come from the generator; README.md states the Web API version the release was generated from.
- **Secrets.** Never commit API keys; the examples read `UNIONE_API_KEY` from the environment.

## Integrating UniOne with this package

Full guide: [README.md](README.md). NestJS integration of the [UniOne Node.js SDK](https://github.com/unione-repo/unione-node-sdk) (`unione`): the API client in the NestJS DI container, a webhook endpoint with signature check, a Nodemailer transport that sends through `email/send`.

Install:

```bash
npm install unione-nestjs nodemailer
```

Requirements: Node.js 20.19+ / 22.12+ (ESM package), NestJS 10–11.

Rules that generated code must follow:

- Server-side only. Read the API key from `UNIONE_API_KEY`; never put it in browser or mobile code, never commit it.
- Base URL `https://api.unione.io/en/transactional/api/v1` (an account registered on another host uses that one: `eu1.unione.io`, `us1.unione.io`); every method is POST with a JSON body; auth header `X-API-KEY`. The package does all of it.
- First email without DNS: `domain/get-sandbox-domain` → `confirmed-email/create` (the user clicks the link within 48 hours) → `email/send` from `noreply@<sandbox-domain>` to the confirmed address. Account API key only; up to 10 confirmed addresses, 100 emails a day; the domain expires after 31 days.
- Never ship a sandbox domain as the production sender (it is not in `domain/list`); read `from_email` from config. Production needs a verified domain: `domain/get-dns-records` → DNS records → `domain/validate-verification-record`, `domain/validate-dkim` → `domain/list`.
- Set `message.idempotence_key` on retryable sends; retry network errors, `429` and `5xx` with backoff, not other errors unchanged. Up to 500 recipients and 10 MB per request, each attachment up to 7 MB; always `body.html` or `body.plaintext`.
- Delivery events via webhook (`webhook/set`), not polling; the webhook endpoint of this package checks the `auth` signature of every notification.
- Keep the default unsubscribe and tracking behaviour; changes go through UniOne support.
- Do not invent methods or fields. Check the [README](README.md), the [API reference](https://docs.unione.io/en/web-api-ref) or [llms.txt](https://docs.unione.io/llms.txt).

### Configuration

The API key goes to `UNIONE_API_KEY`.

```typescript
// .env: UNIONE_API_KEY=YOUR_API_KEY, UNIONE_HOST=us1.unione.io
import { Module } from "@nestjs/common";
import { UniOneModule } from "unione-nestjs";

@Module({
  imports: [
    UniOneModule.forRoot(), // or forRoot({ apiKey, host, timeout, webhookKey, webhookPath })
    // UniOneModule.forRootAsync({ inject: [ConfigService], useFactory: (c: ConfigService) => ({ apiKey: c.get("UNIONE_API_KEY") }) }),
  ],
})
export class AppModule {}

// main.ts: the webhook signature is checked over the raw body
const app = await NestFactory.create(AppModule, { rawBody: true });
```

| Option | Environment variable | Default | Description |
|---|---|---|---|
| `apiKey` | `UNIONE_API_KEY` |  | User or project API key (required). |
| `host` | `UNIONE_HOST` | `api.unione.io` | API host (datacenter: `api.unione.io`, `eu1.unione.io`, `us1.unione.io`) or a full base URL. |
| `timeout` | `UNIONE_TIMEOUT` | `30` | Request timeout, seconds. |
| `webhookKey` | `UNIONE_WEBHOOK_KEY` |  | API key the webhooks are signed with (the key of the user/project of the webhook), if it differs from the API key. |
| `webhookPath` | `UNIONE_WEBHOOK_PATH` | `/unione/webhook` | Path of the webhook endpoint. |

### Sending mail

Messages of the Nodemailer go through [email/send](https://docs.unione.io/en/web-api-ref#email-send): from, to/cc/bcc, reply-to, subject, HTML and text parts, attachments, inline images and `X-*` headers.

```typescript
import { MailerModule } from "@nestjs-modules/mailer";
import nodemailer from "nodemailer";
import { UniOneTransport } from "unione-nestjs";

// @nestjs-modules/mailer
MailerModule.forRootAsync({
  inject: [UniOneTransport],
  useFactory: (transport: UniOneTransport) => ({ transport, defaults: { from: "Shop <shop@example.com>" } }),
});

// or plain Nodemailer
const transporter = nodemailer.createTransport(app.get(UniOneTransport));
await transporter.sendMail({ from: "shop@example.com", to: "user@example.com", subject: "Hi", html: "<b>Hi</b>" });
```

### Webhooks

The endpoint answers `GET` with 200 OK (the URL check of [webhook/set](https://docs.unione.io/en/web-api-ref#webhook-set)) and accepts the `POST` notifications: it checks the `auth` field (MD5 of the request body in which the `auth` value is replaced by the API key), answers 401 to a wrong signature, and passes the notification and each of its events to the application.

```typescript
import { Injectable } from "@nestjs/common";
import { UniOneWebhooks } from "unione-nestjs";

@Injectable()
export class DeliveryListener {
  constructor(webhooks: UniOneWebhooks) {
    webhooks.onEvent(async (event, user) => {
      console.log(event.eventName, event.eventData?.email, event.eventData?.status);
    });
  }
}
```

Register the URL of the endpoint with `webhook/set`, e.g. `https://example.com/unione/webhook`.
